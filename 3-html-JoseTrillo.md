3. Listas y tablas en HTML

Las listas y tablas en HTML permiten organizar información de manera clara dentro de una página web.

Listas en HTML

Las listas sirven para mostrar varios elementos de forma ordenada o mediante viñetas.

Lista no ordenada

La etiqueta <ul> se utiliza para crear una lista con viñetas. Cada elemento se coloca utilizando <li>.

Ejemplo:

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Lista ordenada

La etiqueta <ol> se utiliza para crear una lista cuyos elementos aparecen numerados.

Ejemplo:

<ol>
    <li>Primero abrir el editor</li>
    <li>Crear el archivo HTML</li>
    <li>Escribir el código</li>
</ol>

Tablas en HTML

Las tablas sirven para organizar información en filas y columnas.

La etiqueta <table> se utiliza para crear una tabla.

Ejemplo:

<table border="1">
    <tr>
        <th>Nombre</th>
        <th>Edad</th>
        <th>Curso</th>
    </tr>
    <tr>
        <td>José</td>
        <td>20</td>
        <td>Programación</td>
    </tr>
    <tr>
        <td>Ana</td>
        <td>21</td>
        <td>Base de Datos</td>
    </tr>
</table>
