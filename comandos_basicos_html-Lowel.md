Que es una etiqueta HTML?
Es un codigo que se utiliza para estructurar y organizar el contendido de una pagina web. Le indican al navegador como mostrar textos, imagenes, enlaces y otros elementos. Las etiquetas siempre llevan <> y, generalmente se colocan en pares, una para apertura y otra para cierre.

Ejemplos de etiquetas basicas:
<body>: Contiene todo el contenido visible dentro de la pagina web, como texto, imagenes, enlaces y tablas.
Ejemplo:
<body>
   todo lo que ve el suuario
</body>

<head>: Contiene metadatos y informacion sobre el documento que no se ve directamente en la pagina, como el titulo de la pestaña o enlaces a archivos CSS.
Ejemplo:
<head>
  <title>Mi Página Web</title>
</head>

<h1> hasta <h6>: Se utilizan para crear titulos y subtitulos con jeraquia, entre más aumenta el valor del numero más pequeño es el titulo.
Ejemplo:
<h1>Título Principal</h1>

<strong>: Funciona para colocar el texto en negrita.
Ejemplo:
Este texto es <strong>muy importante</strong>.

<span>: Es un contenedor que se usa para aplicar estilos visuales como el color, a una parte especifca del texto sin romper la linea.
Ejemplo:
Hoy el cielo está <span style="color: blue;">azul</span>.

<br>: Hace un salto de linea en el texto sin crear un nuevo parrafo.
Ejemplo:
Primera línea.<br>Segunda línea.

<img>: Se usa para añadir imagenes.
Ejemplo:
<img src="foto.jpg" alt="Descripción de la foto">

<a>: Crea un hipervinculo que se utiliza para enlazar la pagina actual con otra web o archivo.
Ejemplo:
<a href="https://google.com">Ir a Google</a>

<p>: Para colocar parrafos.
Ejemplo:
<p>Este es el primer párrafo de mi página web con información importante.</p>
