# Ejemplo mínimo de una página HTML completa



## Estructura básica



```html

<!DOCTYPE html>

<html lang="es">

<head>

  <meta charset="UTF-8">

  <title>Mi primera página</title>

</head>

<body>

  <h1>Hola mundo</h1>

  <p>Esta es mi primera página web.</p>

</body>

</html>

```



## Explicación de cada etiqueta



- `<!DOCTYPE html>`: indica al navegador que el documento usa HTML5. Va siempre en la primera línea.

- `<html>`: etiqueta raíz que contiene todo el documento. El atributo `lang="es"` indica que el contenido está en español.

- `<head>`: sección de información sobre la página. Su contenido no se muestra en pantalla.

- `<meta charset="UTF-8">`: define la codificación de caracteres para que se vean bien las tildes y la ñ.

- `<title>`: texto que aparece en la pestaña del navegador.

- `<body>`: contiene todo el contenido visible de la página.

- `<h1>`: título principal del contenido.

- `<p>`: párrafo de texto.
